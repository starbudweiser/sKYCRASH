# Changelog — sKYCRASH

Notes de version / release notes (EN + FR). Translations in IT and ES: see the Nexus Mods page.

## Unreleased / Non publié

**English**

- Animated launch screen, like the other Skyrim Tools: the eye spins into place and the title appears letter by letter, the main window opens after 2 seconds and the splash leaves after 4 seconds. With "Reduce motion" enabled in macOS, the splash stays still for the same duration.

**Français**

- Écran de lancement animé, comme les autres Skyrim Tools : l'œil se met en place en tourbillon et le titre apparaît lettre par lettre ; la fenêtre principale s'ouvre au bout de 2 secondes et le splash s'efface au bout de 4. Avec « Réduire les animations » activé dans macOS, le splash reste fixe, pendant la même durée.

## 1.1.0

**English**

- Crash Logger 1.25: the C++ exception section is read (type, HRESULT, throwing module), with advice for the usual DirectX errors under CrossOver.
- Fix: the new CALL STACK section title was reported as an empty call stack, and "C++ Exception" was shown as an unknown exception.
- Each suspect DLL or plugin now shows the mod that provides it (Mod Organizer 2 instance or mABBAJACK installation).
- New-version notice: the app checks the latest GitHub release once a day and offers to open the Nexus page, remind you later or skip that version. Nothing is downloaded or installed.

**Français**

- Crash Logger 1.25 : la section d'exception C++ est lue (type, HRESULT, module qui l'a levée), avec des conseils pour les erreurs DirectX courantes sous CrossOver.
- Correctif : le nouveau titre de la section CALL STACK était déclaré comme une pile d'appels vide, et « C++ Exception » comme une exception inconnue.
- Chaque DLL ou plugin suspect indique maintenant le mod qui le fournit (instance Mod Organizer 2 ou installation mABBAJACK).
- Avertissement de nouvelle version : l'appli consulte la dernière release GitHub une fois par jour et propose d'ouvrir la page Nexus, de rappeler plus tard ou d'ignorer cette version. Rien n'est téléchargé ni installé.
