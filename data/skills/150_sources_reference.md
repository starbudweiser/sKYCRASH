- SKSE : skse.silverlock.org (versions SKSE par version du jeu) ; dépôt ianpatt/skse64.
- Crash Logger SSE : github.com/alandtse/CrashLoggerSSE (versions, issues, format des rapports).
- Community Shaders : github.com/community-shaders/skyrim-community-shaders (releases, issues de crash, compatibilité).
- Address Library : page Nexus « Address Library for SKSE Plugins » (all-in-one pour AE, versions dédiées pour SE).
- LOOT : github.com/loot/loot ; Wabbajack : github.com/wabbajack-tools/wabbajack ; Mod Organizer 2 : github.com/ModOrganizer2/modorganizer ; Vortex : github.com/Nexus-Mods/Vortex.
- Communautés : r/skyrimmods (fils de crashs récents, très utile pour une mise à jour de jeu), Nexus Mods (sections Posts/Bugs de chaque mod), Discord des modlists Wabbajack, Steam (annonces de mises à jour du jeu).
- Analyseur communautaire de Phostwood (phostwood.github.io/crash-analyzer) pour des crash logs .NET Script Framework / Crash Logger.
- Les notes « Veille » ajoutées automatiquement par l'application proviennent de ces sources ; ce sont des indices non vérifiés : toujours recouper avec les logs.
